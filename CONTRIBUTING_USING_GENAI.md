# Guideline for AI-generated code contributions to SAP Open Source Software Projects

AI-generated code or content can be contributed to this open source project if the following conditions are met:

1. **Compliance with AI Tool Terms and Conditions**: Contributors must ensure that the AI tool's terms and conditions do not impose any restrictions on the tool's output that conflict with the project's open-source license (Apache License 2.0) or with SAP's open-source IP policies. The generated output must comply with the [Open Source Definition](https://opensource.org/osd).

2. **Filtering of third-party material**: Contributors must use AI tool features that filter or flag material that is similar to third-party content. If similarities to existing third-party material are flagged, contributors must check the relevant licensing terms for that material before including it in a contribution.

3. **Third-party copyrighted material**: If the generated contribution includes or is derived from third-party copyrighted material, contributors must ensure they have the right to use that material under the project's license. Where required, contributors must include the appropriate copyright notice, attribution, and license information.

4. **Employer policies**: If the contribution is made in the context of employment, contributors must ensure that their use of AI tools and the resulting contribution complies with their employer's internal policies.

---

By contributing AI-generated content to this project, you confirm that you have reviewed the output, take responsibility for its correctness and license compliance, and accept the [Developer Certificate of Origin](CONTRIBUTING.md#developer-certificate-of-origin-dco) in the same way as for any other contribution.
